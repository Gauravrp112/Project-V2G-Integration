# Project-V2G-Integration
THIS PROJECT IS ABOUT VEHICLE TO GRID INTEGRATION IDEA WHERE THE ELECTRIC VEHICLE'S BATTERIES
<br>
ARE USED AS STORAGE UNITS AND THE STORED POWER IS USED WHEN THE GRID REQUIRES POWER DURING PEAK LOADS.
<br>
THIS PROJECT CONSIST OF OVERALL PCB's SELF MADE INVERTER, RECTIFIERS AND BATTERY MANAGEMENT SYSTEM.
